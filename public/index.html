Private because it's local

Most assistants are a chat window connected to someone else's server. Locus runs its speech recognition and language model on your PC, so your requests never leave it.

Works offline
Every feature works with the network unplugged.
No account
Nothing to sign up for or log in to.
No telemetry
Locus doesn't report anything back. Not usage, not crashes, nothing.
Online is opt-in
Features that need the internet, like web search, will come later and stay off until you turn them on.

Careful with your files

An assistant that can delete things has to be cautious. Locus sorts every action by how much it could cost you.

  1. Looks something up Just does it. CPU usage, finding a file
  2. Makes a change you can undo Does it, then tells you what changed. Opening an app, moving a file
  3. Could lose unsaved work Asks first, and cancels if you don't answer in 15 seconds. Closing an app
  4. Deletes or powers off Shows exactly what will happen and waits for you to press a key or click Confirm. A spoken “yes” isn't enough. Deleting a file, shutting down

Deleted files always go to the Recycle Bin, so you can get them back. Apps are closed the normal way, never force-quit, so their own “Save changes?” prompt still appears.

Will it run on my PC?

Probably. Locus is built for ordinary laptops, not gaming rigs. On first run it checks your hardware and picks models that fit.

MinimumRecommended
Windows10 or 11, 64-bit11, 64-bit
Memory8 GB16 GB
Graphics cardNot neededNot needed

Disk spaceAbout 5 GBAbout 10 GB

You'll be able to install it with the Windows installer, or from the command line if you prefer the terminal. Both give you the same app. macOS and Linux are planned after the Windows release.
